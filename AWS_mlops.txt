Open the port 9000 in the EC2 Security Group (AWS Console)
----------------------------------------------------------------

EC2 Console → Instances → select your instance → Security → click Security Group → Edit inbound rules → Add rule:

Type: Custom TCP

Port range: 9000

Source: your IP /32 (recommended) or 0.0.0.0/0 for quick testing (less secure)
